# 0.11.1 출시 결과 (2026-11-13)

0.11.0 출시 직후 사용자 보고로 나온 긴급 수정 두 가지를 담은 패치입니다.

## 범위
- 오른쪽 위 창 버튼(최소화·최대화·닫기) 중 닫기가 화면 밖으로 밀려 보이지 않던 문제. 원인은 `App.axaml`의 고정 47px 이동. 이제 `MainWindow.AlignCaptionButtons`가 닫기 버튼의 실제 위치를 재서 오른쪽 끝에 맞춘다. 버튼 모양도 Windows 11에 맞췄다(제목 줄 높이를 채우는 46px, 가리키면 옅은 회색, 닫기는 #C42B1C 배경에 흰 X).
- 아주 큰 쪽이 섞인 문서를 열면 첫 쪽이 오른쪽으로 치우쳐 보이던 문제. 문서 폭이 가장 넓은 쪽에 맞춰지고 모든 쪽이 그 가운데에 놓이는데 가로 스크롤이 0에서 시작했기 때문. 열 때 현재 쪽을 화면 가운데에 맞춘다(사용자가 만지기 전까지 창 크기 변화를 따라감). 쪽 이동도 쪽이 화면에 들어오면 가운데로 간다.

## 검증
- 전체 테스트 통과(App.Tests 964개 포함).
- 앱을 직접 띄워 확인: 최대화 창에서 세 버튼이 오른쪽 끝에 붙고, 가리킴 색(회색·빨강+흰 X)이 맞음. 큰 쪽이 섞인 시험 PDF가 최대화 창에서 가운데에 열림.
- 확인하지 못한 것: 모니터 배율 125%·150%, 단추를 눌러 닫기·최소화가 되는지, 3번째 쪽이 큰 실제 파일(HL-505328), 설치본·msix의 깨끗한 컴퓨터 설치.

## 실수 기록
- 새 작업 폴더(worktree)에서 `build/package-msix.ps1`을 그냥 돌리면 `build/msix/store-identity.json`(git에 없음, 메인 폴더에만 있음)을 못 찾아 자리표시자 신원(PLACEHOLDER)으로 만든다. 스토어 검증에서 패키지 ID·게시자 불일치로 거절돼 알았다. 스토어용은 반드시 `-IdentityFile "<메인 폴더>/build/msix/store-identity.json"`을 지정한다.
- 거절된 업로드는 지우고 다시 올렸다. 스토어 목록의 릴리스 노트(한국어·영어)에 0.11.1 두 줄을 추가했다.
