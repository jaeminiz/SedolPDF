**사용할 프로그램:** `D:\INBOX_WP\95. Claude\PDF EDITOR\artifacts\m5-task8-build\SedolPDF.exe` (더블클릭하면 실행됩니다)

**시험용 PDF가 있는 폴더:** `D:\INBOX_WP\95. Claude\PDF EDITOR\spikes\out\m5-user-test\`
(파일 이름이 `01-ime.pdf`, `02-table.pdf` … 처럼 항목 번호와 같습니다. 모두 직접 지어낸 예시 글이라 회사 도면이 아닙니다.)

## 시작하기 전에 알아 둘 것
- 문서를 여는 방법: SedolPDF를 실행 → 왼쪽 위 **열기**(또는 키보드 `Ctrl + O`) → 위 폴더의 파일 선택.
- **편집 탭 → 텍스트 편집** 단추를 눌러 두면, 문서의 글줄을 한 번 누를 때 편집 창이 뜹니다.
- 편집 창에서 **확정**하는 키는 `Ctrl + Enter`, **취소**는 `Esc`, 그냥 `Enter`는 줄바꿈입니다.
- 시험하다 마음대로 고쳐도 괜찮습니다. **저장하지 않으면** 원래 파일은 그대로입니다. 되돌리려면 `Ctrl + Z`.
- 이상한 점을 찾으면 **어느 파일의 어느 줄을 눌렀는지, 무엇을 입력했는지, 화면이 어땠는지(사진이나 캡처)** 를 알려 주세요.

## 1번. 한글 입력 중 Enter·Esc (`01-ime.pdf`)
1. **열 파일:** `01-ime.pdf` (한글 문단 3개가 있는 쪽)
2. **누를 곳:** 편집 탭 → 텍스트 편집 → 첫 문단 아무 줄이나 한 번 클릭 → 파란 점선 상자와 편집 창이 뜹니다. 창 안의 글 맨 끝을 클릭해 커서를 둡니다.
3. **입력할 글:** 키보드를 한글 모드로 두고 `가나다`를 칩니다. **"다"를 다 치기 전, 밑줄이 그어진 채 글자가 만들어지는 중**에 `Enter`를 한 번 누릅니다. 이어서 다시 `라마바`를 치다가 중간에 `Esc`를 한 번 누릅니다.
4. **기대하는 모습:** 글자를 만드는 도중의 Enter·Esc는 글자를 끝내는 데만 쓰이고, **편집 창이 닫히지 않고 확정도 안 됩니다.** 글자가 다 끝난(밑줄 없는) 뒤에 `Esc`를 누르면 그때는 취소되어 창이 닫히고, `Enter`는 줄을 바꿉니다.
5. **이상하면 알려 줄 것:** 창이 갑자기 닫혔는지, 글이 확정돼 문서에 들어갔는지, 어떤 순서로 눌렀는지.

## 2번. 표 칸 눌러 보기 (`02-table.pdf`)
1. **열 파일:** `02-table.pdf` (왼쪽 위에 보통 문단 1개, 오른쪽 가운데에 칸 나눈 표, 왼쪽 아래에 선 없는 표)
2. **누를 곳:** 텍스트 편집을 켜고 오른쪽 표의 **"배관 배치도"** 글자를 클릭합니다. 같은 방식으로 왼쪽 아래 표의 **"해수 펌프"**도 눌러 봅니다.
3. **입력할 글:** 아무 글이나 한두 글자 붙여 보고 `Ctrl + Enter`. (그냥 `Esc`로 닫아도 됩니다.)
4. **기대하는 모습:** 여러 줄 창이 아니라 **한 줄짜리 작은 창**이 뜨고, 화면 아래쪽에 "표 안의 글처럼 보여 한 줄만 편집합니다"라는 안내가 잠깐 나옵니다. 반대로 왼쪽 위의 보통 문단을 누르면 여러 줄 창이 뜹니다.
5. **이상하면 알려 줄 것:** 표 칸인데 여러 줄 창이 뜬 곳(눌렀던 글자), 또는 안내가 안 보였는지.
   - 참고: 편집 탭의 **"한 줄만"** 단추를 켠 뒤에는 보통 문단을 눌러도 한 줄 창만 떠야 합니다.

## 3번. 문단이 틀리게 묶였을 때 (`03-merged.pdf`)
1. **열 파일:** `03-merged.pdf`. 위쪽은 문단 두 개가 빈 줄 없이 붙어 있고("배관 지지대는…"과 "밸브 작동기는…"), 아래쪽은 문단 바로 밑에 서명 줄이 있습니다.
2. **누를 곳:** 텍스트 편집을 켜고 위쪽 두 번째 문단의 줄 **"밸브 작동기는…"**을 누릅니다. → 상자가 **6줄**(두 문단 전부)로 묶이는 것이 정상입니다(일부러 틀리게 묶이게 만든 파일입니다). 편집 창 맨 위의 작은 단추 **"위 줄 제외"**를 눌러 첫 문단 줄이 빠지게 합니다(키보드는 `Alt + Shift + ↑`). 필요하면 **"아래 줄 포함"**(`Shift + ↓`)도 눌러 봅니다.
3. **입력할 글:** 아직 아무것도 고치지 마세요. 단추 누르기는 **글을 고치기 전에만** 됩니다.
4. **기대하는 모습:** 단추를 누를 때마다 점선 상자가 한 줄씩 줄거나 늘고, 창 아래의 "줄 N/최대 M" 숫자가 같이 바뀝니다. 원하는 줄만 남기고 낱말 하나를 고쳐 `Ctrl + Enter`를 누르면 **상자 안의 줄만** 바뀌고 다른 문단은 그대로입니다.
5. **이상하면 알려 줄 것:** 단추가 안 눌리거나 줄 수가 안 바뀐 경우, 고친 뒤 옆 문단이 같이 변한 경우. (아래쪽 서명 줄 시험도 해 보세요: "예비품은…"을 눌렀을 때 서명 줄이 상자에 들어가는지, 들어갔다면 "아래 줄 제외"로 뺄 수 있는지.)

## 4번. 원래 글꼴에 없는 글자 넣기 (`04-subset.pdf`)
1. **열 파일:** `04-subset.pdf` (위: 영문 문단 하나(Arial 글꼴), 아래: 명조 느낌의 영문 문단 하나(Georgia 글꼴))
2. **누를 곳:** 텍스트 편집 → 위쪽 영문 문단의 아무 줄 클릭.
3. **입력할 글:** 창 안의 글 끝에 한글 `한글 글자를 넣어 봅니다`를 붙이고 `Ctrl + Enter`. 같은 방법으로 아래쪽(명조 느낌) 문단에도 한글을 붙여 봅니다.
4. **기대하는 모습:** 확정하면 화면 아래에 **"원래 글꼴에 없는 글자가 있어 기본 글꼴로 바꿨습니다."** 알림이 뜹니다. 한글이 정상 글자로 보입니다(네모 ▯로 나오면 안 됩니다). 고친 줄은 원래와 모양이 조금 다를 수 있습니다. 아래쪽 문단은 **명조 계열 모양**으로 바뀌는 것이 정상입니다.
5. **이상하면 알려 줄 것:** 알림이 안 뜨거나, 한글이 네모·빈칸으로 나오거나, 다른 줄까지 글꼴이 바뀐 곳.

## 5번. 같은 문단을 두 번 고치기 (`05-twice.pdf`)
1. **열 파일:** `05-twice.pdf` (한글 문단 2개)
2. **누를 곳:** 텍스트 편집 → 첫 문단 클릭 → 낱말 하나를 바꾸고(예: "도면"→"설계도면") `Ctrl + Enter`.
3. **입력할 글:** 같은 문단을 **한 번 더 클릭** → 이번에는 문장 끝에 `추가합니다`를 붙이고 `Ctrl + Enter`. 한 번 더 클릭해서 낱말 하나를 또 바꿔도 좋습니다.
4. **기대하는 모습:** 두 번째 클릭 때 **처음 고친 글이 포함된 상태로** 편집 창이 열립니다. 확정해도 **글자가 겹쳐 보이거나 이전 글이 뒤에 비쳐 보이지 않고** 새 글로 교체됩니다. `Ctrl + Z`를 한 번 누르면 **마지막 편집만** 되돌아갑니다.
5. **이상하면 알려 줄 것:** 글이 겹쳐 두 겹으로 보이는지, 되돌리기를 눌렀을 때 몇 번 눌러야 원래대로 돌아오는지.
   - 저장하고 나서 다른 프로그램(Acrobat, 크롬)으로 열어 보면 더 확실합니다.

## 6번. 회전된 쪽 · 큰 배율 · 암호 PDF
### 6-가. 회전된 쪽 (`06a-rotated90.pdf`)
1. **열 파일:** `06a-rotated90.pdf` (쪽이 90도 돌려져 있어 글이 옆으로 누워 보임)
2. **누를 곳:** 텍스트 편집 → 문단의 줄 클릭.
3. **입력할 글:** 낱말 하나를 고치고 `Ctrl + Enter`.
4. **기대하는 모습:** 점선 상자와 편집 창이 **글 방향에 맞게** 놓이고, 고친 뒤에도 글이 쪽의 같은 자리에 같은 방향으로 보입니다.
5. **이상하면 알려 줄 것:** 상자가 글과 어긋나거나, 고친 글이 엉뚱한 방향·자리에 나온 경우.

### 6-나. 큰 배율 125 % · 150 % (`06b-zoom.pdf`)
- 먼저 **Windows 화면 배율**을 바꿉니다: 바탕화면에서 마우스 오른쪽 클릭 → **디스플레이 설정** → **배율** 칸에서 `125%` 또는 `150%` 선택. (시험이 끝나면 원래 값, 보통 100%로 돌려 두세요. 일부 프로그램은 다시 실행해야 새 배율이 적용됩니다. SedolPDF도 닫았다 다시 여세요.)
1. **열 파일:** `06b-zoom.pdf` (작은 글자로 문단이 많은 쪽)
2. **누를 곳:** 텍스트 편집 → 아무 문단의 줄 클릭. 문서 화면 확대 단추로 확대·축소한 뒤에도 다시 해 봅니다.
3. **입력할 글:** 낱말 하나 수정, 또는 글 끝에 `확인`을 붙이고 `Ctrl + Enter`.
4. **기대하는 모습:** 점선 상자와 편집 창이 **글 바로 위에 정확히** 겹쳐 놓이고, 편집 창의 글자와 단추가 잘리지 않습니다.
5. **이상하면 알려 줄 것:** 상자가 글과 어긋나는 배율(125/150%), 창 안 글자·단추가 잘리는 곳, 화면 캡처.

### 6-다. 암호 PDF (`06c-encrypted.pdf`)
- **시험 전용 비밀번호: `test1234`** (이 파일에만 쓰는 가짜 비밀번호입니다. 실제 서류의 비밀번호가 아닙니다.)
1. **열 파일:** `06c-encrypted.pdf` → 비밀번호 창이 뜨면 `test1234` 입력.
2. **누를 곳:** 텍스트 편집 → 문단의 아무 줄 클릭.
3. **입력할 글:** 한두 글자 고치고 `Ctrl + Enter`.
4. **기대하는 모습:** 암호 문서는 문단 편집을 지원하지 않으므로 **여러 줄 창이 아니라 한 줄 창**이 뜨고, 그 이유를 알리는 안내가 잠깐 나옵니다. 한 줄 편집 자체는 정상적으로 되어야 합니다.
5. **이상하면 알려 줄 것:** 여러 줄 창이 떴거나, 안내가 없거나, 한 줄 편집이 안 되는 경우.

## 알려진 문제 (이미 알고 있으니 새로 찾지 않으셔도 됩니다)
스크린샷으로 확인된 점들이며, 아직 고치지 않았습니다.
1. **글꼴이 바뀌면 줄바꿈이 원본과 많이 달라질 수 있습니다.** (고친 줄이 기본 글꼴로 바뀌면 글자 폭이 달라져서, 문단 전체의 줄이 끊기는 자리가 원본과 다르게 나옵니다.)
2. **편집 창 안에서 보이는 줄바꿈이 실제 결과와 다릅니다.** 창 안에서는 낱말 중간에서도 끊겨 보이지만, 실제 결과 줄 수는 **창 아래의 "줄 N/최대 M"** 숫자가 맞습니다.
3. **편집 창 아래의 안내 글씨가 작고 좁게 접혀** 읽기 불편합니다.

## 다음에 같은 샘플을 다시 만들려면 (개발자용)
```
dotnet run -c Release --project spikes/M5.UserSamples -- <출력 폴더>
```
이 PC에서는 프로그램이 `.pdf` 파일을 바로 쓰면 접근 거부가 나서 `.pdf.tmp`로 저장됩니다. 저장 뒤 확장자를 `.pdf`로 바꾸고 `-- <출력 폴더> --verify`를 붙여 다시 실행하면 PDFium으로 열어 문단 인식 결과를 점검합니다.
