# 0.12.0 시스템 글꼴 사용 (설계 메모, 2026-11-13)

[font-roadmap.md](font-roadmap.md)의 0.13.0 항목을 0.12.0으로 당겼다(사용자 결정). 서식 보존([0.12.0-format-preservation.md](0.12.0-format-preservation.md)) 위에 얹는다.
범위는 **글 상자·타자기·설명선(FreeText 주석)** 이다. 쪽 본문 글 편집(TextEdit)은 지금처럼 Noto만 쓴다(후속 후보).

## 1. 핵심 결정 요약

| # | 결정 |
|---|---|
| 1 | 설치된 글꼴은 **글꼴 폴더를 직접 훑어** 읽는다(`C:\Windows\Fonts`, `%LOCALAPPDATA%\Microsoft\Windows\Fonts`). 헤더(name·OS/2·fvar 표)만 읽는 자체 파서. 새 의존성 없음. |
| 2 | 주석 모델의 `FontName`이 곧 "고른 글꼴"이다. null이면 지금처럼 고딕/명조(Noto). 값이 있으면 그 이름의 시스템 글꼴로 그리고, 없으면 `TextFamily`(고딕/명조)의 Noto로 대체한다. **이름은 항상 보존**한다. |
| 3 | 배치·화면·AP·저장이 모두 **같은 글꼴 파일**(HarfBuzz)을 쓴다. 글꼴 키는 기존 `Family` 문자열을 넓혀 `"sys:<얼굴 id>"`로 둔다. |
| 4 | 저장 시 서브셋을 넣는다. TrueType은 `/CIDFontType2` + `/FontFile2` + `/CIDToGIDMap /Identity`(글리프 번호 유지 서브셋), CID 방식 CFF는 지금 길(`/CIDFontType0C`). |
| 5 | **포함 금지(fsType) 글꼴은 목록에 보이지 않는다.** 문서가 그런 글꼴을 가리키면 Noto로 그리고 속성 패널에 "대체됨"을 알린다. |
| 6 | `.ttc`는 얼굴 번호로 지원, **가변 글꼴·이름 방식 CFF·CFF2는 목록에서 뺀다**(0.12.0). |
| 7 | 받는 PC에 글꼴이 없어도 PDF 안의 서브셋으로 보인다. SedolPDF로 다시 편집하면 Noto로 대체하고 이름은 남긴다. |
| 8 | 진짜 굵은/기울임 얼굴(예: `malgunbd.ttf`)이 있으면 그것을 쓰고 가짜 굵게·기울임은 끈다. 없으면 지금처럼 가짜. |
| 9 | 번들 글꼴은 늘리지 않는다. |

## 2. 글꼴 목록 읽기 (①)

**왜 Avalonia/DirectWrite가 아닌가:** 이름 목록은 얻을 수 있지만, 우리는 배치(HarfBuzz)·윤곽선·서브셋에 **글꼴 파일 바이트**가 필요하다. Avalonia의 `FontManager.SystemFonts`는 파일 경로를 주지 않고, DirectWrite로 경로를 얻으려면 COM 상호 운용(IDWriteLocalFontFileLoader)이 필요하다. 폴더를 직접 읽으면 Appearance 계층(UI 없음)에서 시험할 수 있고 의존성이 늘지 않는다.

- `SystemFontCatalog`(PdfEditor.Appearance/Fonts): 두 폴더의 `.ttf/.otf/.ttc`를 훑어 얼굴(face)마다 다음을 읽는다.
  - 가족 이름(name ID 16, 없으면 1)과 하위 이름(17/2) — **모든 언어**(한국어 이름 "맑은 고딕"과 영어 "Malgun Gothic" 둘 다 찾기용으로 색인), 전체 이름(4), PostScript 이름(6).
  - OS/2: `usWeightClass`, `fsSelection`(기울임), `fsType`(포함 허용), `sFamilyClass`(세리프 여부 → 대체 시 고딕/명조).
  - 윤곽선 종류: `glyf`(TrueType) / `CFF `(CID 방식이면 허용) / `CFF2`·`fvar`(가변) → 제외.
- 처음 필요할 때(글꼴 목록을 열거나 FontName이 있는 주석을 그릴 때) **백그라운드에서 한 번** 훑고 앱 실행 동안 기억한다. 표 머리만 읽으므로 수백 개 파일이어도 빠르다.
- 화면에 보이는 이름: 한국어 이름이 있으면 한국어, 없으면 영어.
- 이름 찾기: 공백·대소문자를 무시하고 가족·전체·PostScript 이름 어느 것과 같아도 찾는다(`/DA`의 `MalgunGothic`, CSS의 `맑은 고딕` 모두).

## 3. 모델과 그리기 (②③⑤)

- `Annotation.FontName`(0.12.0 서식 보존에서 추가)을 그대로 쓴다. 새 필드는 없다.
  - UI에서 시스템 글꼴을 고르면 `FontName = 가족 이름`, `TextFamily = 그 글꼴의 세리프 여부`(대체용).
  - UI에서 "고딕(기본)"/"명조(기본)"을 고르면 `FontName = null`.
  - `FreeTextRichText.FamilyList`는 FontName이 있으면 항상 `'이름',sans-serif|serif`를 쓴다(이전의 "계열이 같을 때만" 조건은 위 규칙 때문에 필요 없어진다).
- 해석: `PaintContext.Resolve(annotation)` → (AppFont, 글꼴 키, 가짜 굵게, 가짜 기울임). 순서:
  1. FontName이 시스템에 있고 포함 가능하면 → 굵기·기울임이 가장 가까운 얼굴.
  2. 아니면 → `TextFamily`의 Noto(지금과 같음).
- 글꼴 키(`TextRunOp.Family`·`FontUse.Family`): `""`(고딕), `"serif"`(명조), `"sys:<경로>#<얼굴 번호>"`. 화면(AppearanceGeometry)·AP·저장이 같은 키로 같은 AppFont를 받는다.
- 글꼴 파일은 처음 쓸 때 읽고 최근 8개만 메모리에 둔다(`.ttc`는 수십 MB가 될 수 있음).
- 글 상자 안 편집기(Avalonia TextBox)는 같은 가족 이름을 `FontFamily`로 받아 편집 중 모양도 비슷하게 한다.

## 4. 저장 시 포함 (④)

- `FontSubsetter.Subset`에 얼굴 번호와 **글리프 번호 유지(HB_SUBSET_FLAGS_RETAIN_GIDS)** 를 더한다. 화면이 전체 글꼴의 글리프 번호로 배치했으므로 서브셋 뒤에도 같은 번호여야 한다(지금 CID 검증과 같은 원칙).
- TrueType: `/Type0` → `/CIDFontType2`, `/FontFile2`, `/CIDToGIDMap /Identity`, 글자 코드 = 글리프 번호, `/W`, `/ToUnicode`.
- CID 방식 CFF: 지금 `FontEmbedder` 길(코드 = CID).
- `/BaseFont`: `ABCDEF+<PostScript 이름>`.
- 글꼴 파일을 읽을 때 fsType을 다시 확인한다(목록을 만든 뒤 파일이 바뀌었을 수 있다). 금지면 그 얼굴은 "없음"으로 보고 Noto로 대체한다. 화면과 저장이 같은 해석을 거치므로 화면과 파일이 어긋나지 않는다.

## 5. 특수한 경우 (⑥)

| 경우 | 0.12.0 처리 |
|---|---|
| `.ttc` 글꼴 모음(바탕·굴림 등) | 얼굴 번호로 읽고 서브셋하면 단일 글꼴이 나온다. 지원. |
| 가변 글꼴(`fvar`) | 목록에서 뺀다. 이름으로 가리키면 Noto 대체. 기본 인스턴스만 넣으면 뷰어마다 달라질 수 있어 확인 후 후속에서. |
| 이름 방식 CFF `.otf`, `CFF2` | 목록에서 뺀다(CID 보장 불가). |
| 포함 금지·미리보기만 허용(fsType) | 목록에서 뺀다. 문서가 가리키면 Noto 대체 + 안내. |
| 받는 PC에 글꼴 없음 | PDF 안 서브셋으로 다른 뷰어에서 그대로 보인다. SedolPDF는 AP를 그대로 쓰고(옮기기만 하면 다시 그리지 않음), 내용을 고치면 Noto로 대체 + 안내, 이름은 보존. |
| 시스템에 있는데 그 글자가 없음(예: 영문 글꼴에 한글) | 지금 Noto와 같이 빈 글리프가 된다. 0.12.0은 **글자별 대체를 하지 않는다**(후속 후보). UI 목록에서 한글 지원 여부를 표시하지는 않는다. |

## 6. UI (②)

- 속성 패널·서식 탭의 글꼴 상자: 맨 위 "고딕(기본)", "명조(기본)" 그대로, 그 아래 구분선 뒤에 설치된 글꼴(가나다·ABC순). 목록은 처음 열 때 채운다.
- 고른 글꼴이 대체 중이면 상자 아래 "이 PC에 없는 글꼴이라 기본 글꼴로 표시합니다"(또는 "포함이 허용되지 않은 글꼴") 한 줄.
- 기본 서식 설정(`AppSettings.TextFont`)은 "Sans"/"Serif" 외에 글꼴 이름도 받는다.

## 7. Store(MSIX)에서 확인 (⑦)

MSIX 데스크톱 앱은 전체 신뢰(runFullTrust)라 `C:\Windows\Fonts` 읽기는 허용된다. 사용자별 글꼴 폴더(`%LOCALAPPDATA%`)는 MSIX 파일 가상화 대상이지만 **읽기는 실제 위치로 통과**하는 것으로 안다 — 실제 스토어 빌드에서 확인이 필요하다.

확인 방법(손 시험표에 포함):
1. 스토어(MSIX) 빌드 설치 → 글 상자 → 글꼴 목록에 "맑은 고딕"이 있는가(시스템 폴더).
2. OFL 글꼴 하나를 "사용자용으로 설치"(우클릭 → 설치, 관리자 아님) → 앱 재시작 → 목록에 있는가(사용자 폴더).
3. 그 글꼴로 글 상자를 만들어 저장 → 다른 뷰어(Acrobat/Edge)에서 같은 모양인가, 문서 속성의 글꼴 목록에 "포함된 하위 집합"으로 나오는가.

## 7.1 시험
- 단위: name/OS2 파서(ttc 포함), 이름 찾기(한국어·영어·PostScript), fsType 걸러내기, TrueType 서브셋 임베드 → PDFium으로 다시 읽어 글자가 같은지, FontName 대체 규칙.
- 시스템에 의존하는 시험(맑은 고딕)은 글꼴이 없으면 건너뛴다.

## 8. 하지 않는 것
- 글자별 대체(한글 없는 글꼴에 한글), 가변 글꼴, 쪽 본문 글 편집의 시스템 글꼴, 글꼴 미리보기 그림, 글꼴 번들 추가.
