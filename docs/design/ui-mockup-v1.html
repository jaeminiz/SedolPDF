Mac 스타일(B)과 다른 점

  • 도구 버튼에 글자가 붙어 처음 쓰는 사람도 바로 알아봄. 대신 툴바 폭을 더 차지함
  • 제목 표시줄의 탭으로 여러 PDF를 한 창에서 전환
  • 패널이 바탕 위에 떠 있는 카드라 구역 구분이 뚜렷함

개발 측면

  • Avalonia에 Fluent 테마가 기본 포함되어 B′가 초기 공수가 적음
  • Mac 스타일은 테마를 직접 만들어야 함. 대신 한번 만들면 화면 전체에 일관되게 적용됨
  • 두 테마 모두 같은 화면 구조라 나중에 설정에서 테마 전환 기능으로 제공 가능
