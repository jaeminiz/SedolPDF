# 0.12.0 서식 보존 — 설계 메모 (2026-11-13)

범위: [font-roadmap.md](font-roadmap.md)의 "0.11.2 긴급 수정" 1~4(0.12.0에 묶기로 결정)와 "0.12.0 — 서식 보존" 1·2. 글꼴 번들·가짜 굵게 구조·시스템 글꼴은 건드리지 않는다.
굵게·기울임 UI(0.12.0 3번)는 이미 `Annotation.Bold/Italic`과 `/SedolFmt`·`/DS`의 `font-weight:bold`로 값과 맞아 있어, 이번에는 **읽기**만 고친다.

## 실제 값으로 확인한 것 (시험 자료 3쪽 파란 글상자)
`/RC` 본문(`<body style>`)은 **Arial 12pt 검정 보통**이고, 실제 글자 서식은 그 안의 `<span style>`(맑은 고딕 10pt 굵게 700 #0000FF)에 있다.
그래서 "body 먼저"인 지금 순서로는 `/RC`를 읽어도 검정 12pt가 된다 → **span → body → /DS → /DA** 순으로 읽어야 한다.
(로드맵에는 body·span이 구분돼 있지 않았다. 이 항목이 로드맵 대비 달라진 점.)

## 읽기 (AnnotationReader / DefaultStyle)
- `/RC`는 `/DS` 유무와 관계없이 읽는다. 글자 색·크기·글꼴 가족·굵게·기울임 = 첫 span → body → `/DS` → `/DA`.
  - 크기는 `/RC`·`/DS`가 `/DA`보다 먼저다(지금은 `/DA`가 먼저). `/DA`에 `Tf`가 없는 Acrobat 파일의 12pt 오류가 이것이다.
- 굵게: `font-weight`가 `bold`/`bolder`/600 이상. `font` 약식의 `500`은 굵게가 아니다. 기울임: `italic`/`oblique`.
  `/SedolFmt`가 있으면 그 비트에 합친다(OR). 밑줄·취소선은 `/SedolFmt`만(기존).
- **`HasDs`의 뜻은 그대로**(`/DS`가 있는가). 테두리 색(`/DA`의 RG) 규칙이 이것에 의존하므로 `/RC`만 있는 주석의 테두리 해석은 건드리지 않는다.

## 모델 변경 (Annotation, 최소)
- `FontName`(string?): `/DS`·`/RC`에서 읽은 원래 첫 글꼴 이름(예: `맑은 고딕`). 일반 글꼴군(serif 등)은 이름으로 안 친다.
- `DaFont`(string?): `/DA`의 글꼴 자원 이름(없으면 null → 쓸 때 `/Helv`).
- 쓰기(`FreeTextRichText.Da/Ds/Rc`)는 값이 있으면 그 이름을 돌려 쓴다. 단 사용자가 고딕/명조를 바꿔 `FontName`의 분류(`DefaultStyle.FamilyOf`)와 어긋나면 기본 이름을 쓴다. 이름에 `' " ; < > & \`가 있으면 쓰지 않는다(CSS·XML 주입 방지).
- 편집 전 값 비교를 위해 저장 항목(`AnnotEntry`)에 `Original`(읽은 그대로의 모델)을 둔다. 모델 자체에 원본을 싣지 않는다(`Annotation`은 비교·복사가 잦다).

## 이동·크기 조절 — 모양을 다시 그리는 조건
저장 때 손댄 원본 FreeText 하나마다:
1. **평행 이동만 했다**(= `Original`과 비교해 `Rect`/`TextBox`/`Vertices`/`Leader2`/`ModifiedAt`만 같은 양만큼 옮겨졌고 크기 동일, 나머지 모든 필드 동일) → `/AP`를 그대로 두고 새 `MoveAnnotation(dx, dy)` 패치로 `/Rect`·`/CL`·`/SedolCL2`만 옮긴다. `/DA`·`/DS`·`/RC`·모양은 원본 그대로.
2. 그 밖의 변경(내용·서식·테두리·**크기 조절** 포함) → 지금처럼 `AnnotationPainter`로 다시 그린다.
   - 크기 조절을 1번에 넣지 않는 이유: AP를 새 `/Rect`에 맞추면 PDF 뷰어가 모양을 늘려 글자가 찌그러지고, 줄바꿈도 다시 계산되지 않는다. 읽기가 고쳐지므로 다시 그려도 서식은 유지된다.
   - 로드맵 3항의 "이동·크기 조절만 한 주석" 중 크기 조절은 위 이유로 **다시 그림**을 택했다(결정 변경점).
3. 다시 그릴 때도 글자 내용·서식이 `Original`과 같으면 `/RC`를 새로 쓰지 않고 원본 `/RC`를 둔다 → 한 주석 안의 span별 서식(글자마다 색·굵기가 다른 것)이 크기 조절·테두리 변경 뒤에도 남는다. 내용이나 글자 서식을 바꾸면 한 서식으로 다시 쓴다(편집 UI가 한 상자 한 서식이므로 어쩔 수 없음).

화면(타일)은 손댄 원본을 PDFium이 아니라 앱이 모델에서 그리므로, 읽기 수정(위 1절)이 화면에서 파랑·10pt·굵게를 지키는 쪽이고, 저장 파일의 모양은 이 절이 지킨다.
