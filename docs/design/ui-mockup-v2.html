PDF Editor · 화면 구성 2차 시안

PDF-XChange 구성 기반 재설계

PDF-XChange Editor의 화면 요소(메뉴 탭과 리본, 문서 탭, 왼쪽 패널 아이콘 막대, 썸네일 패널, 하단 상태 표시줄)를 그대로 유지하고 모양만 다시 그렸습니다. 기능 위치는 PDF-XChange 사용자가 바로 찾을 수 있게 두고, 버튼 수와 시각적 잡음을 줄였습니다. 두 시안 모두 주석 탭에서 클라우드를 선택한 상태입니다.

PDF-XChange 화면에서 바꿀 점

유지할 것

  • 메뉴 탭 → 기능 그룹 구조 (리본)
  • 선택한 도구에 맞춰 나타나는 "형식" 탭
  • 문서 탭, 왼쪽 패널 전환 아이콘 막대, 썸네일 패널
  • 상태 표시줄의 페이지 크기(W/H), 커서 좌표(X/Y), 페이지 이동, 배율

바꿀 것

  • 색이 섞인 큰 아이콘 → 단색 선 아이콘, 상태는 강조색 하나로 표시
  • 리본 한 화면에 버튼 40여 개 → 탭당 10~15개, 나머지는 "더보기"
  • 빠른 실행 도구 모음과 검색창이 흩어진 상단 → 제목 표시줄 한 줄로 정리
  • 패널 테두리·구분선 겹침 → 여백과 카드로 구역 구분
  • 오른쪽 속성 창을 기본으로 표시 (PDF-XChange는 별도로 열어야 함)
