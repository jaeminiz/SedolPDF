# 객체·주석 복사·붙여넣기 손 시험표 (0.9.0)

- 날짜: 2026-11-10
- 대상 빌드: `src/PdfEditor.App/bin/Debug/net10.0-windows/win-x64/SedolPDF.exe`
- 설계서: `docs/superpowers/specs/2026-11-10-object-copy-paste-design.md`
- 자동 시험은 합성 입력(헤드리스)이라 실제 키보드·마우스·메뉴는 아래 표로 직접 확인한다. 결과는 "통과 / 실패(상태)"로 적는다.

준비: 글자·경로(도형)·그림·폼(도면의 묶음)이 섞인 PDF 한 개(예: 도면 PDF)와, 쪽이 2개 이상인 PDF, 권한이 걸린 PDF(복사 금지), 90° 돌린 쪽이 있는 PDF.

| # | 시험 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|---|
| 1 | 같은 쪽 Ctrl+C/V (경로·글자·그림·폼) | 편집 탭 → 개체 편집, 개체를 하나 눌러 고르고 Ctrl+C, Ctrl+V. 종류별로 반복 | 같은 모양의 개체가 화면 기준 오른쪽 아래로 약 10pt 비켜 생기고, 새 개체가 선택되어 있다. 다시 옮기기·크기 바꾸기·지우기 가능 | |
| 2 | 두 번 이상 붙이기 | 같은 클립보드로 Ctrl+V를 세 번 | 붙일 때마다 10pt씩 더 비킨다(겹쳐 쌓이지 않고 계단처럼) | |
| 3 | 회전된 쪽에서 붙이기 | 90° 돌린 쪽에서 개체를 복사·붙이기 | 화면에서 오른쪽 아래로 비킨다(위·왼쪽이 아님). 개체 방향은 원래와 같다 | |
| 4 | 다른 쪽에 붙이기 | 1쪽 개체 복사 → 2쪽으로 이동(쪽 넘기기) → Ctrl+V | 지금 보고 있는 쪽의 같은 자리에 붙는다. 쪽 밖이면 안으로 당겨진다. 글꼴이 다른 쪽에서도 원래 글꼴로 보인다 | |
| 5 | 잘라내기와 실행 취소 | 개체 여러 개 고르고 Ctrl+X → Ctrl+V → 실행 취소(Ctrl+Z) 한 번 | 원래 개체가 사라지고 붙인 뒤, 실행 취소 한 번에 붙이기가 취소된다. 한 번 더 취소하면 잘라낸 개체가 돌아온다 | |
| 6 | 복제 | 개체를 고르고 Ctrl+D | 클립보드 내용은 그대로(다른 걸 복사해 둔 뒤 Ctrl+D 해도 Ctrl+V는 복사해 둔 것이 붙는다). 한 번에 취소된다 | |
| 7 | 여러 개 한꺼번에 | 사각형으로 여러 개를 고르고 Ctrl+C/V | 모두 같은 간격으로 함께 붙고, 겹침 순서가 원래와 같다. 실행 취소 한 번 | |
| 8 | 주석 복사 | 주석 선택 도구로 사각형·구름·텍스트 상자·스탬프·연필 주석을 각각 Ctrl+C/V | 새 주석이 비켜서 생기고 작성자는 지금 사용자, 시각은 지금. 텍스트 바꾸기 묶음은 둘이 함께 복사. 형광펜·밑줄·취소선(단독)은 복사 안 되고 알림이 뜬다 | |
| 9 | 저장 후 다시 열기 | 위 시험 1·4·7을 한 뒤 저장 → 닫고 다시 열기 | 붙인 개체가 화면에서 본 자리에 원본과 같은 모양으로 있다(글자 간격·점선 포함). 폼·셰이딩은 벡터 그대로 | |
| 10 | 다른 문서 | 문서 A에서 복사 → 문서 B(다른 탭 또는 다른 창)에서 Ctrl+V | 알림 "다른 문서의 개체는 아직 붙일 수 없습니다", 아무것도 바뀌지 않는다 | |
| 11 | 원천 쪽 지우기 | 1쪽 개체를 2쪽에 붙인 뒤 1쪽 삭제 시도 | 알림 "이 쪽에서 복사해 붙인 개체가 다른 쪽에 있어 지울 수 없습니다…", 쪽 그대로. 붙인 개체를 지운 뒤에는 지워진다 | |
| 12 | 권한 막힌 문서 | 복사 금지 권한 PDF에서 개체 선택 후 Ctrl+C | 알림 "이 문서는 권한 설정 때문에 개체를 복사할 수 없습니다" | |
| 13 | 오른쪽 클릭 메뉴 | 개체 편집·주석 선택 도구에서 개체 위 오른쪽 클릭 / 빈 곳 오른쪽 클릭 | 잘라내기·복사·붙여넣기·복제·삭제가 보인다. 아무것도 안 골랐으면 잘라내기·복사·복제·삭제가 흐리고, 복사해 둔 게 없거나 다른 문서 것이면 붙여넣기가 흐리다. 삭제는 Delete 키와 같다 | |
| 14 | 글자 복사와 충돌 없음 | 텍스트 선택 도구로 글자를 끌어 고른 뒤 Ctrl+C | 지금처럼 글자가 클립보드에 복사된다(개체 복사로 가로채지 않음). 개체 편집 도구에서 아무것도 안 고르고 Ctrl+C도 같다 | |
| 15 | 글 입력 중 | 한 줄 편집 창/텍스트 상자 입력 중 Ctrl+C/V/D | 입력창의 글자 복사·붙여넣기만 일어난다(개체는 안 건드림) | |
| 16 | 돌린 쪽 화살표 | 90°/180° 돌린 쪽에서 개체를 고르고 화살표 키 | 화면에서 누른 방향 그대로 움직인다 | |
| 17 | 붙인 개체 다시 고르기 | 붙인 뒤 다른 곳을 눌러 선택을 풀고, 사각형으로 붙인 개체를 끌어 고름 | 붙인 개체도 사각형 선택에 잡힌다 | |
| 18 | 회전이 다른 쪽에 붙이기 | 0° 쪽 개체를 복사 → 90° 쪽에 Ctrl+V | 보이는 자리와 방향이 그대로 옮겨진다 | |
| 19 | 개체 회전 | 개체를 고르면 위쪽에 둥근 손잡이가 생긴다. 끌어서 돌린다(Shift = 15° 단위) | 돌린 대로 보이고, 저장 후 다시 열어도 같다. 원본 개체도 돌려진다 | |
| 20 | 영역 강조 복사 | 주석 선택 도구로 영역 강조(사각형 형광펜)를 Ctrl+C/V | 새 영역 강조가 비켜서 생긴다 | |

알려진 한계(설계서 6절): 원본 개체의 클립(잘라내기 영역)은 복사하지 않음 / 저장 전 화면에서 복사한 글자는 자간이 빠지고 폼·셰이딩은 그림으로 보임(저장한 파일은 정확) / 회전이 다른 쪽으로 붙이면 보이는 방향이 다를 수 있음 / 문단 편집 줄·찾아 바꾸기 조각은 복사 불가 / 다른 문서로는 붙일 수 없음 / 개체와 주석을 함께 붙이면 실행 취소 두 번.
